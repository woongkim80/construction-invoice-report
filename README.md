# 🏗️ 건설현장 공무 자재송장 자동화 및 작업일보 생성기
> **Zero-Setup & Mobile-Friendly 현장 공무 전용 스마트 자재·일보 관리 시스템**

건설현장 공무 및 관리 직원이 매일 처리하는 레미콘·철근 송품장 사진을 분석하여 품명, 규격, 수량, 차량번호 등을 추출하고, 수기 작업 메모를 본사 보고용 표준 일일 작업일보 서식으로 자동 정제하여 엑셀(.xlsx)로 변환해 주는 웹 애플리케이션입니다.

---

## 🌟 주요 기능

1. **📸 자재 송품장 및 영수증 AI 자동 분석 (OCR)**
   - 현장에서 촬영한 레미콘 송품장, 철근 납품확인서, 자재 영수증 사진 업로드
   - **Google Gemini 1.5 Flash** 멀티모달 모델을 통한 핵심 데이터 추출:
     - 납품일자, 공급업체 상호, 납품 현장명
     - 자재 품명, 규격(강도/슬럼프/철근호칭), 입고 수량 및 단위
     - 단가, 공급가액 합계, 운송차량번호, 인수자 서명 확인
   - 단건 송장 즉시 **전용 서식 엑셀(.xlsx)** 다운로드 지원

2. **📝 현장 수기 메모 ➔ 본사 보고용 일일 작업일보 자동 정제**
   - 현장 반장님의 거친 수기 메모나 음성 텍스트를 입력하면 공학 표준 용어로 자동 정제
   - 표준 일일 작업일보 양식 구성:
     - 공사 개요 (공사명, 일자, 날씨, 기온, 작성자, 진도율)
     - 금일 주요 작업 내용 (공종별 분류 및 상세 위치)
     - 투입 인력 현황 (직종별 인원수 및 투입 구역)
     - 금일 자재/장비 입고 내역 (당일 송장 데이터와 원클릭 자동 연동)
     - 명일 작업 계획 및 현장 안전관리 특이사항
   - 본사 보고용 **표준 일일 작업일보 엑셀 서식(.xlsx)** 즉시 다운로드

3. **📊 누적 자재 입고 현황 및 공무 집계표**
   - 공급업체별 자재 납품 규모 및 품목별 입고 비중 인터랙티브 차트(Plotly)
   - 전체 누적 입고 내역을 필터링하여 **통합 자재 관리 엑셀(.xlsx) 파일**로 1초 만에 다운로드

4. **🗂️ 송장 및 작업일보 기록 관리 (CRUD)**
   - 오기입된 송장 데이터 세부 수정 및 삭제
   - 이전 작업일보 이력 조회 및 재다운로드

5. **☁️ 구글 스프레드시트(Google Sheets) 영구 연동 (선택 사항)**
   - 클라우드 서버가 재부팅되어도 데이터가 영구 보존되도록 구글 시트와 실시간 양방향 동기화 지원

## 🛠️ 기술 스택
- **Language**: Python 3.11+
- **Web UI & Dashboard**: Streamlit (모바일 반응형 뷰포트 지원)
- **AI Vision / LLM**: Google Gemini API (`gemini-1.5-flash` 멀티모달 모델)
- **Data & Excel**: Pandas, openpyxl (고품질 서식 엑셀 출력)
- **Data Visualization**: Plotly Express
- **Database**: SQLite3 (`site_materials.db`, 내장 단일 파일 DB) & Google Sheets

## 🚀 빠른 시작 가이드 (로컬 실행)

### 방법 1: 원클릭 자동 실행 (가장 추천 👍)
1. 폴더 안의 **`run.bat`** 파일을 더블 클릭합니다.
   - Python 가상환경(`.venv`)과 필수 라이브러리를 **자동으로 감지하여 설치**합니다.
   - 설치 완료 후 기본 웹 브라우저(Chrome/Edge)에 `http://localhost:8501` 대시보드가 자동으로 열립니다.

### 방법 2: 스마트폰 외부 접속 (ngrok)
1. `run.bat`을 실행하여 대시보드를 켭니다.
2. **`run_ngrok.bat`** 파일을 더블 클릭합니다.
3. 터미널에 표시되는 `Forwarding https://xxxx.ngrok-free.app` 주소를 스마트폰 브라우저에 입력하면 현장에서 즉시 카메라로 송장을 찍어 올릴 수 있습니다.

## ⚙️ AI 프롬프트 및 추출 항목 커스터마이징 안내

현장 특성에 따라 송장에서 추가 항목(예: '배치플랜트 번호', '레미콘 배합번호', '시험 성적서 번호' 등)을 더 추출하고 싶으실 때는:
1. **`ai_extractor.py`** 파일의 `INVOICE_PROMPT` JSON 스키마에 원하는 항목을 추가합니다.
2. **`database.py`**의 `INVOICE_COLUMNS`와 테이블 컬럼에 필드를 추가합니다.
3. **`excel_exporter.py`**의 `col_mapping`에 한글 컬럼명을 추가하면 엑셀 파일에도 즉시 반영됩니다.
